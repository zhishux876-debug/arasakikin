# アラサー基金 — YAAAC 応募ページ（配信用リポジトリ）

**山梨アラサーアクションアイデアコンテスト（YAAAC）** の応募ページを配信するための
リポジトリです。`master` に push すると、検査を全部通ったときだけ GitHub Pages が更新されます。

## ここは「工房」ではありません

制作は別の作業場（ローカルの `lp-factory`）で行い、**このリポジトリには配信に必要なものだけ**
を置いています。ここに無いもの（他案件、参照サイトの実測、施主提供の写真、
採否の記録、複数案の比較）は、意図的に持ち込んでいません。**公開リポジトリだからです。**

したがって、**このリポジトリのファイルを直接編集しないでください。**
直しても工房側に戻らず、次の同期で上書きされます。直すのは工房側です。

## 何が配信されるか

```
output/yaaac-stamp-dial-craft/     ← 公開する案（DESIGN.md の canonical: yes）
    index.html                     応募ページ本体（単一HTML・外部依存は Google Fonts のみ）
    404.html
    DESIGN.md                      意匠の正本。実装と食い違ったら直すのは実装の側
briefs/yaaac.md                    文言の正本（確定コピー60件）
```

配信先のディレクトリは、この設定ファイルのどこにも書いていません。
`scripts/publish_target.py` が `DESIGN.md` の `canonical: yes` を読んで決めます。
**決定の在りかを2箇所に増やさないため**です。

## push したとき何が起きるか

`.github/workflows/publish.yml` が、次を上から順に通します。**1つでも落ちたら配信しません。**

| 検査 | 見るもの |
| :--- | :--- |
| `ctrl_char_lint.py` | 潰れた制御文字（他の検査を黙って無効化するので最初） |
| `design_spec_lint.py` | 意匠の正本からの逸脱 |
| `design_spec_lint.py --canonical-audit` | 公開してよい案が1つか |
| `interface_lint.py` | ソースの静的検査 |
| `verify.py --fixed briefs/yaaac.md` | **実機レンダリング**・確定コピー60件の一字一句照合 |

## いまの状態

- `DESIGN.md` の `status` が「施主承認待ち」のあいだは、**自動で noindex** が付きます
  （生成される `robots.txt` が `Disallow: /`）。URL を知っている人だけが見られます
- 検索結果に出してよくなったら、`status` を「施主承認済み」に書き換えて push します

詳しい手順は `DEPLOY.md` にあります。

## 応募先

応募は Google フォームです。ページ内の「エントリーはこちら」から開きます。
**URL をページにベタ貼りしない**のは、施主の概要書 §5-5 の指定です。
